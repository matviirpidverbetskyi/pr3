# Practical Work 3

Простий FastAPI-проєкт, створений за допомогою uv.

## Вимоги
- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

## Запуск
```bash
git clone https://github.com/matviirpidverbetskyi/pr3.git
cd pr3
uv sync
uv run fastapi dev main.py
```
Після запуску відкрийте http://127.0.0.1:8000
